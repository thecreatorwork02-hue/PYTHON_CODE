# PYTHON_CODE
# 🐍 Python Learning Journey & Mini-Projects

Welcome to my first GitHub repository! This repository is a complete collection of my Python practice scripts and mini-projects, tracking my progress from basic syntax and data types to data structures, conditional logic, and loops.

---

## 📂 Repository Contents

### 1. External Modules & Libraries
* **Text-to-Speech (`pyttsx3`):** Initializes an offline speech engine to convert text into spoken audio.
* **Random Joke Generator (`pyjokes`):** Fetches and displays random programming jokes in the terminal.

### 2. Mini Calculators & Interactive Tools
* **Bill & Tip Splitter:** Calculates the total bill per person after adding a custom tip percentage.
* **Song Budget Calculator:** Computes the total budget of a song based on its duration and cost per second.
* **Student Grade & Percentage Calculator:** Calculates total marks and percentage across Maths, Physics, and Chemistry, and checks for a 90%+ score.
* **Anime Scene Prompt Generator:** Uses f-strings to combine user inputs (character, action, time, location, mood) into a 90s anime scene prompt.
* **Audio File Formatter:** Formats song titles and singer names into clean `.mp3` filenames while fixing double-space errors.
* **Hook Analyzer:** Measures text length and searches for specific hook keywords (`Stop`, `wait`, `hold`, `freeze`).
* **Music Playlist Manager:** Uses lists to sort existing songs, append a user-submitted song, and remove the first track.
* **Color Palette Updater:** Uses a dictionary to look up primary/secondary/tertiary colors and dynamically update key-value pairs.
* **Unique Tag Collector:** Uses a `set` to collect user-entered tags while automatically preventing duplicates.

### 3. Conditional Logic & Loops
* **AI Comment Spam Filter:** Uses `if-elif-else` statements and string matching to detect and flag spam phrases (`click now`, `free money`, `free trading course`).
* **Student Percentile Tier Checker:** Evaluates a student's percentage to classify them into `Elite` (90%+), `Advanced` (75%+), or `Beginner` tiers.
* **Voter Eligibility Validator:** Checks user age against voting requirements while handling edge cases like `0` or negative numbers.
* **While Loop Counter:** Demonstrates basic loop iteration by counting from 1 to 76.

### 4. Core Python Fundamentals & Cheat Sheets
* **Variables & Data Types:** Examples of integers, floats, strings, booleans, `None`, `type()` checking, and typecasting.
* **Strings & Escape Characters:** Reference notes on positive/negative slicing, step indexing, built-in string methods (`upper()`, `lower()`, `replace()`, `split()`, `find()`, `count()`, `capitalize()`), and escape sequences (`\n`, `\t`, `\\`).
* **Lists & Tuples:** Practice scripts demonstrating list mutability (`append()`, `insert()`, `remove()`, `pop()`, `sort()`, `reverse()`, `clear()`) vs. tuple immutability.
* **Dictionaries & Sets:** Reference examples covering dictionary methods (`items()`, `keys()`, `update()`, `get()`) and set operations (`add()`, `remove()`, `union()`, `intersection()`, `issubset()`).

## 💻 How to Run These Scripts

1. **Clone the repository**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project folder**
   ```bash
   cd your-repository-name
   ```

3. **Install required external packages**
   ```bash
   pip install pyttsx3 pyjokes
   ```

4. **Run any script**
   ```bash
   python filename.py
   ```
